## 📌 Como usar

1. **Capturar** → Tudo entra pelo `00_Inbox` (via Telegram, voz, ou digitando)
2. **Processar** → Mova notas para a pasta correta e adicione tags
3. **Conectar** → Use `[[links]]` para criar conexões entre ideias
4. **Revisar** → Consulte os MOCs (Maps of Content) de cada área

- `#inbox` — Nota não processada

- `#tarefa` — Ação pendente
- `#referencia` — Material de consulta
- `#projeto` — Relacionado a um projeto ativo

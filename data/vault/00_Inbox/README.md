# 📥 Inbox

> Área de captura rápida. Tudo que chega sem classificação cai aqui primeiro.

## Como funciona

- Notas enviadas pelo **Telegram** (áudio transcrito ou texto) chegam aqui automaticamente
- Cada nota recebe frontmatter YAML com data, origem e tags
- **Processe regularmente**: mova para a pasta correta (`01`, `02`, `03` ou `04`)

## Template de Nota

```yaml
---
date: 2024-01-01
source: telegram | manual | web
tags: [inbox]
status: pendente
---
```

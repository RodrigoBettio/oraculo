# Proteção de Dados

## Resumo
A aula aborda os conceitos fundamentais de proteção de dados no design de sistemas, focando em segurança, conformidade com a LGPD e GDPR, minimização de dados, criptografia em trânsito (TLS) e em repouso, além de cuidados rigorosos com logs e credenciais.

## Tópicos Principais
- Riscos e ameaças à segurança de dados
- Princípio de menor privilégio
- Rotação regular de credenciais e chaves de API
- Conformidade (LGPD e GDPR)
- Minimização de dados coletados
- Uso de HTTPS/TLS
- API Gateway
- Cuidados com logs de requisições e credenciais

## Detalhes dos Segmentos
- **00:00 - 02:04**: Visão geral dos riscos de proteção de dados.
- **02:05 - 03:12**: Princípio de menor privilégio e regulamentações.
- **03:13 - 04:36**: TLS, API Gateways e segurança em logs.

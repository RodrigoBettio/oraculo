# 12. Cache

## Resumo
A aula discute as estimativas de cache para o planejamento de aplicações, analisando a hierarquia de velocidade e os tempos de acesso a dados em diferentes níveis de armazenamento, desde a cache L1 da CPU e memória RAM até SSDs e HDs.

## Tópicos Abordados
- Estimativas de Cache
- Latência e Overhead de Rede
- Hierarquia de Memória (Cache L1, RAM, SSD, HD)
- Tempos de Acesso a Dados
- Dados Mais Acessados

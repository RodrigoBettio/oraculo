# 12. Cache

## Resumo
Nesta aula do curso sobre cache, aborda-se o conceito fundamental de cache para otimizar o acesso a dados de forma rápida, reduzindo a carga em bancos de dados e sistemas. São discutidos os tipos de cache (como Redis, Memcached, CDN), a ordem de grandeza nas requisições, trade-offs de armazenamento e invalidação, estratégias de cache (read-side, write-side), além de exemplos práticos de como e onde aplicar cache em sistemas web modernos.

## Tópicos
- Conceito de Cache
- Ordem de Grandeza e Requisições
- Trade-offs e Invalidação de Cache
- Níveis de Cache (Computador, Aplicação, CDN)
- Estratégias de Read Side e Write Side
- Cache em Bancos de Dados e Sistemas Distribuídos

# 16. Requisitos e Estimativas

## Resumo
Nesta aula sobre estimativas no System Design, o instrutor detalha como realizar estimativas aproximadas (chutes calibrados) durante entrevistas de System Design. São abordados conceitos de ordens de grandeza, SLAs, conversão de unidades de armazenamento (bytes a terabytes), latência de rede, tempo de acesso a disco (Disk Seek) versus memória principal (Main Memory), e um estudo de caso prático simulando o dimensionamento para uma aplicação estilo Instagram.

## Tópicos Abordados
- Importância das estimativas em System Design
- SLAs e Ordens de Grandeza
- Conversão e Compressão de Dados
- Latência de Rede e Round Trip
- Disk Seek vs Main Memory
- Estudo de caso do Instagram

## Código e Timestamps
*Nenhum código de programação puro foi apresentado nesta aula, apenas conceitos de cálculo de estimativas e arquitetura.*

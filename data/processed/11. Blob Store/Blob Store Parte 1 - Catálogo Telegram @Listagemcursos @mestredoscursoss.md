# 11. Blob Store

## Resumo
Nesta aula, abordamos o problema crucial do armazenamento de arquivos, contrastando o uso de servidores simples com arquiteturas escaláveis. Discutimos as limitações dos File Systems tradicionais (hierárquicos) e introduzimos o conceito de Object Storage / Blob Store (Binary Large Object) como a solução padrão da indústria para aplicações modernas na nuvem.

## Tópicos Principais
- O problema do armazenamento local vs distribuído
- Limitações de File Systems em escala
- Introdução ao File Systems tradicionais
- Object Storage e Blob Stores (AWS S3, Azure Blob, Google Cloud Storage)
- Vantagens e desvantagens de File Systems vs Blob Stores
- Uso de UUIDs, metadados e CDNs
- Aplicação prática em arquiteturas de nuvem

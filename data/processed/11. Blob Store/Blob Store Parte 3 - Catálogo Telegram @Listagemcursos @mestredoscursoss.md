# Blob Store

## Resumo
A aula encerra o módulo sobre Blob Store, detalhando cenários de uso como o armazenamento de grandes volumes de logs para ingestão em data warehouses e comparando os principais provedores de nuvem (AWS S3, Google Cloud Storage, Azure Blob Storage, Cloudflare R2 e MinIO).

## Tópicos Abordados
- Tipos de Blob Store e Casos de Uso
- Logs em Massa e Data Warehouse
- AWS S3 (Ecossistema, IAM, Ciclo de Vida)
- Google Cloud Storage (GCS)
- Azure Blob Storage
- Cloudflare R2 (Compatibilidade S3)
- MinIO (Solução Self-Hosted para Testes Locais)

Encerramento da série de Blob Store com abertura para dúvidas nos comentários.

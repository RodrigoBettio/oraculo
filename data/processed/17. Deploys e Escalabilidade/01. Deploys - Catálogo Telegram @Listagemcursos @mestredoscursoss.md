# 17. Deploys e Escalabilidade

## Resumo
A aula aborda de forma abrangente as diversas estratégias de deploy de software, comparando métodos manuais e automatizados baseados em CI/CD. São discutidas técnicas avançadas para minimizar o downtime e mitigar riscos em produção, incluindo:
- **Recreate:** Substituição direta com downtime.
- **Rolling Deployment:** Atualização gradual de instâncias.
- **Blue-Green Deployment:** Uso de dois ambientes paralelos (v1 e v2) para troca instantânea de tráfego.
- **Canary:** Liberação gradual de tráfego para um subconjunto de usuários.
- **Shadow Deployment:** Duplicação de tráfego para testes em ambiente real sem afetar os usuários.

Também são abordados temas críticos como compatibilidade de bancos de dados, versionamento de microsserviços e o uso essencial de *Feature Flags* para desacoplar o deploy do release de funcionalidades.

## Tópicos Abordados
1. Deploy Manual e Automatizado
2. Ferramentas de CI/CD (GitHub Actions)
3. Recreate Deployment
4. Rolling Deployment
5. Blue-Green Deployment
6. Canary e Shadow Deployments
7. Compatibilidade de Banco de Dados
8. Feature Flags e Continuous Deployment
